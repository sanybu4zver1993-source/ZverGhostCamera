## 3. Живой чеклист верификации на Redmi 13C (для Сани)
1. **⚠️ БЭКАП ДО СМЕНЫ КЛЮЧА ПОДПИСИ (Шаг Г / Release APK):** Перед установкой `ZverCamera-<tag>-release.apk` поверх `debug`-сборки (или при смене подписи/переустановке) **обязательно сделай копию всех 23+ `.gcf` файлов** из Сейфа (`📦 БЭКАП` / экспорт), т.к. смена подписи APK требует удаления старой debug-версии и меняет ключи `AndroidKeyStore`.
2. **Release APK на GitHub Actions:** После пуша кода в `main` GitHub Actions сам соберёт `ZverCamera-<tag>-release.apk` (и сохранит `debug` APK). Чтобы последующие обновления `release` APK ставились поверх без переустановки, добавь в GitHub Secrets репозитория постоянный keystore (`RELEASE_KEYSTORE_BASE64`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_PASSWORD`, alias `upload`).
3. **Голос (`🐿 БУРУНДУК` / `👹 ДЕМОН`) и Маски (`🤡/🐺/🦊/🐱/🐻/💀/🖼 PNG` + размер):** Проверь пресеты голоса на видео из Сейфа (A/V синхронизация и тембр Media3 Sonic), а в редакторе приватности проверь автодетекцию лиц, выбор масок и слайдер масштаба `60%–220%`.
4. **Night Extension, GPU Визор и быстрый Сейф:** Проверь вкладку `НОЧЬ`, переключение `ВИЗОР ↔ ФОТО ↔ ВИДЕО`, отсутствие фризов при серийном сохранении фото (фоновый `MonoVaultEngine`) и отчёт `CameraDiagnostics`.
